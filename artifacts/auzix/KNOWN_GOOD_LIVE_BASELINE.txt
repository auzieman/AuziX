Derivative rule
---------------

Treat this ISO and its embedded SquashFS as immutable provenance inputs. A
recovery derivative may change only explicitly declared SSH access files,
InstallerEFL payload files, and separately declared fixes for CA discovery and
theme discovery. The preserved baseline's working runtime mount handoff must not
be replaced. Every build must originate from a committed, visible bkc.lab
pipeline run and publish input and output hashes.
